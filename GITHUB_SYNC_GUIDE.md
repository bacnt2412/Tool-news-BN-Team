# 🔄 GITHUB SYNC - Hướng dẫn đồng bộ Cookies & Settings

## 🎯 Mục đích

Tự động tải **cookies.txt** và **settings.json** từ GitHub khi khởi động app.

**Lợi ích**:
- ✅ Cập nhật cookies/settings cho **nhiều máy** cùng lúc
- ✅ Không cần copy-paste thủ công
- ✅ Luôn dùng cookies/API keys mới nhất
- ✅ Quản lý tập trung trên GitHub

---

## 📋 Cấu hình

### 1. Bật/Tắt Auto-Sync

Trong file `config.js`:

```javascript
// Bật auto-sync (khuyến nghị)
AUTO_SYNC_ENABLED: true,

// Tắt auto-sync (dùng cookies/settings local)
AUTO_SYNC_ENABLED: false,
```

### 2. Cấu hình URL GitHub

```javascript
// URL cookies.txt (raw)
COOKIES_GITHUB_URL: 'https://raw.githubusercontent.com/bacnt2412/Tool-news-BN-Team/refs/heads/main/cookies.txt',

// URL settings.json (raw)
SETTINGS_GITHUB_URL: 'https://raw.githubusercontent.com/bacnt2412/Tool-news-BN-Team/refs/heads/main/settings.json',

// Timeout
AUTO_SYNC_TIMEOUT: 30000, // 30 giây
```

**Quan trọng**: Phải dùng URL **raw** của GitHub!

## 📁 Format file trên GitHub

### 1. **cookies.txt**

Format: **Netscape HTTP Cookie File**

```
# Netscape HTTP Cookie File
# This file is generated by yt-dlp.  Do not edit.

.youtube.com	TRUE	/	TRUE	1798377899	__Secure-3PAPISID	wa72thAtAz9PaOdC/AoOWairhVDOi-MUmP
.youtube.com	TRUE	/	FALSE	1798377899	HSID	Aemn6noy9aLaC9wcn
...
```

**Lưu ý**: 
- Phải có header `# Netscape HTTP Cookie File`
- Format chuẩn của yt-dlp
- Tab-separated values

### 2. **settings.json**

Format: **JSON Object**

```json
{
  "microsoft-vision-api-key": [
    {
      "value": "YOUR_MICROSOFT_VISION_API_KEY",
      "end-point": "https://eastus2.api.cognitive.microsoft.com/"
    }
  ],
  "studio-ai-google-api-key": [
    "GOOGLE_VISION_KEY_1",
    "GOOGLE_VISION_KEY_2",
    "GOOGLE_VISION_KEY_3"
  ],
  "google-cloud-api-key": [
    "GOOGLE_TTS_KEY"
  ]
}
```

**Mapping**:
- `microsoft-vision-api-key` → Microsoft Vision OCR
- `studio-ai-google-api-key` → Google AI Studio (Vision OCR)
- `google-cloud-api-key` → Google Cloud TTS

## 🚀 Cách hoạt động

### Flow:

1. **Khởi động app**
2. **Check license** → Thành công
3. **Load config** từ `config.js`
4. **Check `AUTO_SYNC_ENABLED`**:
   - Nếu `true` → Tiếp tục sync
   - Nếu `false` → Bỏ qua, dùng local
5. **Download cookies.txt** từ GitHub
6. **Lưu vào** `{userData}/cookies/cookies.txt`
7. **Download settings.json** từ GitHub
8. **Parse và update** electron-store:
   - `microsoftVision` ← microsoft-vision-api-key
   - `googleVision` ← studio-ai-google-api-key
   - `googleTts` ← google-cloud-api-key
9. **Hiển thị thông báo**:
   - ✅ Success: "Đã đồng bộ cookies và settings từ GitHub"
   - ⚠️ Partial: "Đã đồng bộ cookies từ GitHub" (nếu chỉ 1 cái thành công)
   - ❌ Error: Không hiện thông báo (log ra console)

## 📖 Hướng dẫn sử dụng

### Bước 1: Tạo repo GitHub private

```bash
# Tạo repo mới trên GitHub (private)
# Ví dụ: Tool-news-BN-Team
```

### Bước 2: Upload cookies.txt và settings.json

```bash
# Clone repo
git clone https://github.com/YOUR_NAME/Tool-news-BN-Team.git
cd Tool-news-BN-Team

# Copy cookies và settings vào repo
cp /path/to/cookies.txt .
cp /path/to/settings.json .

# Commit và push
git add cookies.txt settings.json
git commit -m "Add cookies and settings"
git push origin main
```

### Bước 3: Lấy URL raw

1. Vào GitHub repo
2. Click vào file `cookies.txt`
3. Click nút **Raw**
4. Copy URL (dạng `https://raw.githubusercontent.com/...`)
5. Làm tương tự cho `settings.json`

### Bước 4: Cấu hình trong `config.js`

```javascript
// Paste URL vào config.js
COOKIES_GITHUB_URL: 'https://raw.githubusercontent.com/YOUR_NAME/Tool-news-BN-Team/refs/heads/main/cookies.txt',
SETTINGS_GITHUB_URL: 'https://raw.githubusercontent.com/YOUR_NAME/Tool-news-BN-Team/refs/heads/main/settings.json',
```

### Bước 5: Test

```bash
# Khởi động app
npm start

# Check console log:
# ✅ GitHub sync successful: Đã đồng bộ cookies và settings từ GitHub
```

## 🔄 Update cookies/settings

### Khi cần update cookies hoặc API keys:

1. **Sửa file trên GitHub**:
   - Vào repo GitHub
   - Edit `cookies.txt` hoặc `settings.json`
   - Commit changes

2. **Restart app** trên tất cả máy:
   - App sẽ tự động tải file mới từ GitHub
   - Không cần copy-paste thủ công!

**Lưu ý**: GitHub có thể cache file trong vài phút. App đã thêm `?t=${timestamp}` để bypass cache.

## 🛠️ Debug & Troubleshooting

### 1. Check console log

Khi app khởi động, check console:

```
🔄 Auto-sync enabled, syncing from GitHub...
Syncing cookies from GitHub: https://raw.githubusercontent.com/...
✅ Cookies synced successfully: C:\Users\...\cookies\cookies.txt
Syncing settings from GitHub: https://raw.githubusercontent.com/...
✅ Microsoft Vision settings updated
✅ Google Vision settings updated (8 keys)
✅ Google TTS settings updated
✅ Settings synced successfully from GitHub
✅ GitHub sync successful: Đã đồng bộ cookies và settings từ GitHub
```

### 2. Lỗi "Failed to fetch"

**Nguyên nhân**:
- URL không đúng (không phải raw)
- Repo private nhưng không có quyền truy cập
- Mạng chậm/timeout

**Giải pháp**:
- Check lại URL (phải là `raw.githubusercontent.com`)
- Đổi repo thành public (hoặc dùng GitHub token)
- Tăng `AUTO_SYNC_TIMEOUT` trong config

### 3. Lỗi "Invalid cookies format"

**Nguyên nhân**:
- File cookies.txt không có header Netscape
- Format sai

**Giải pháp**:
- Export cookies từ browser bằng extension
- Hoặc copy từ yt-dlp `--cookies-from-browser`

### 4. Settings không update

**Nguyên nhân**:
- Format JSON sai
- Key name không khớp

**Giải pháp**:
- Validate JSON: https://jsonlint.com/
- Check key names:
  - `microsoft-vision-api-key` (không phải `microsoft_vision_api_key`)
  - `studio-ai-google-api-key`
  - `google-cloud-api-key`

### ⚠️ Quan trọng:

### Khuyến nghị:

1. Dùng GitHub repo **private**
2. Chỉ share với team members
3. Định kỳ rotate cookies/API keys

## 💡 Use Cases

### Case 1: Team với nhiều máy

**Vấn đề**: Có 5 người cùng dùng app, mỗi lần update cookies phải copy 5 lần.

**Giải pháp**: 
- Bật auto-sync
- Update cookies trên GitHub 1 lần
- Tất cả máy restart app → Tự động sync!

### Case 2: API keys hết hạn

**Vấn đề**: Microsoft Vision API key hết quota, cần đổi key mới.

**Giải pháp**:
- Sửa `settings.json` trên GitHub
- Tất cả máy restart app → Dùng key mới!

### Case 3: YouTube cookies expire

**Vấn đề**: YouTube cookies hết hạn, không tải được video members-only.

**Giải pháp**:
- Export cookies mới từ browser
- Update `cookies.txt` trên GitHub
- Restart app → Cookies mới!
